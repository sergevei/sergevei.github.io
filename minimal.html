03 — Projects

OBYN — a family of free web apps, built end to end.

Offline-first React PWAs on the frontend and a serverless backend on Cloudflare Workers — an edge API for Google sign-in, paid plans, server-side localization and a Telegram reminder bot. User data stays in the user's own Google Drive: no sign-up and no ads.

OBYN

Flagship
Expense tracker in BYN

Personal finance tracker: expenses by period with charts, budgets and automatic conversion to USD and EUR at the official National Bank of Belarus rate. Runs entirely in the browser.

  • Spending charts by category and period, budgets and period comparison
  • Cross-device sync through the user's own Google Drive, installable offline PWA
  • Telegram reminder bot @OBYNBot: a daily digest of upcoming and overdue bills at the hour the user picks
Backend & Telegram bot
  • Edge API on Cloudflare Workers: OAuth 2.0 code exchange and token refresh with the client secret kept on the server
  • Telegram webhook verified with a secret-token header, an hourly Cron Trigger and storage in Workers KV
  • Reminders at each user's local hour, computed with Intl, daylight saving included
  • Privacy by design: one-tap linking with a random 256-bit key stored only as a SHA-256 hash; /stop deletes everything
  • Covered by Vitest tests against a mocked Telegram API and Workers KV
