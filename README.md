# Siarhei Vei — Cosmic Portfolio

An interactive 3D "solar system" portfolio: a sun at the center with orbiting planets for About, Skills, Experience, and Contact. Click a planet (or the matching menu item) to fly the camera in and open an info panel. Built with vanilla JS and Three.js — no build step, no framework, loads instantly.
